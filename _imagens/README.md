# Fotos das fichas

Coloque aqui uma foto por ficha (planta, fármaco, composto ou homeopático).

**Convenção:** o nome do arquivo de imagem tem que ser **igual ao nome do arquivo `.md`** da ficha.

Exemplos:
- `plantas/pinhao-roxo.md` → `_imagens/pinhao-roxo.jpg`
- `plantas/ipe-roxo.md` → `_imagens/ipe-roxo.jpg`
- `compostos/lapachol.md` → `_imagens/lapachol.jpg`

Formatos aceitos: `.jpg`, `.jpeg`, `.png`, `.webp`.

Se não houver imagem com esse nome, a ficha é publicada normalmente, só sem foto no topo.
O gerador do site (`_site_builder/build.py`) detecta o arquivo automaticamente — não precisa
editar nada no frontmatter nem no HTML.
